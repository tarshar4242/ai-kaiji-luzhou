## 網站結構（兩層 + 事件簿）

```
第一層　2026 工作坊（首頁 index.html）
└─ 第二層　專案列表
   ├─ 蘆洲監理所・AI 開機日
   │    ├─ 互動教學簡報　final.html
   │    ├─ 舉例素材庫　　上台舉例素材庫_最終版.html
   │    ├─ 學員教學版　　教學版.html
   │    └─ 講稿　　　　　講稿_最終版.html
   └─ 📒 工作事件簿　work-log/index.html
        └─ 第三層　事件項目（左側目錄可點選）
           └─ 01 一人工作室・AI 助理團隊
              （後續 02、03 … 陸續加入）
```

- **第一層** = 首頁 `index.html`，列出各專案入口。
- **第二層** = 各專案，例如「蘆洲監理所」與「工作事件簿」。
- **工作事件簿** 本身是一個持續累積的清單，左側目錄、右側內容，每個事件一則紀錄。

## 各頁面說明

| 頁面 | 路徑 | 用途 |
|---|---|---|
| 工作坊總覽 | `index.html` | 第一層首頁，所有專案的入口 |
| 蘆洲監理所・互動簡報 | `final.html` | 47 張投影片、樹狀目錄、現場示範連結 |

| 工作事件簿 | `work-log/index.html` | 左側目錄、右側 iframe，事件清單 |
| └ 01 AI 助理團隊 | `work-log/01-ai-assistant-team.html` | 一人工作室如何用 AI 分工 |

## 怎麼新增一個工作事件

1. 把該事件的 HTML 放到 `work-log/`，命名 `NN-名稱.html`（例如 `02-xxx.html`）。
2. 打開 `work-log/index.html`，在左側目錄 `<nav>` 複製一段 `a.item`，改成新的編號、標題、說明與 `data-src`／`href`。
3. 推上 GitHub，GitHub Pages 約 1～2 分鐘自動更新，網址不變。
